Animation Style System (v11+)

Shared style controls applied to every palette-aware animation (animationPalette, animationSpeed, animationBrightness, trailLength). This is the default "look" for the whole reel — individual steps below inherit these unless you override duration/subtlety per step.
Default nudge subtlety seeds new reminder steps you add in the Sequence tab. Each reminder step can still override it individually.

What "Subtlety" does

Subtlety is a planning-layer dial, not a firmware field. 0 = bold/attention-grabbing nudge at your configured style settings. 100 = whisper-subtle — barely there. Moving the slider computes effective brightness / speed / trail / duration for that nudge, so you can see exactly what to dial in if you want that nudge to hit differently than the rest of your reminders.
